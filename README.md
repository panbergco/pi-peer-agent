# pi-peer-agent

Resident peer agents for pi: standing objectives on a seconds-tick, real resumable
pi sessions, findings pushed into the main agent at inference boundaries (MACP 2.0
delivery contract, pi-native — no MCP, no tmux, no child processes).

Read the spec: [docs/peer-agent-spec.md](docs/peer-agent-spec.md)

Status: spec v1 — implementation starting (P0).
